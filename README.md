# مدیر بستهٔ فارسی ترموکس

مجموعه‌ای از ابزارهای فارسی‌شده برای Termux:

- `pak.sh` — مدیر بستهٔ «پک» (نصب/حذف/جستجو/به‌روزرسانی)
- `bashrc.sh` — محیط فارسی: پرامپت، ۳۰+ میان‌بر و تابع
- `fars.sh` — ورود سریع به پوستهٔ فارسی

## نصب

```bash
cp pak.sh   $PREFIX/bin/پک   && chmod +x $PREFIX/bin/پک
cp fars.sh  $PREFIX/bin/فارس && chmod +x $PREFIX/bin/فارس
cp bashrc.sh ~/.bashrc
```

## استفاده

```bash
پک راهنما
راهنمای_فارسی
```
