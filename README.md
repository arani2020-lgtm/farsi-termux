## 🚀 نصب

```bash
git clone https://github.com/arani2020-lgtm/farsi-termux.git
cd farsi-termux
bash نصب.sh
```

سپس ترمینال را ببندید و دوباره باز کنید — تمام!

## 📦 دستورات اصلی

### پک — مدیر بستهٔ فارسی
```bash
پک نصب python          # نصب بسته
پک جستجو git           # جستجو
پک حذف nano            # حذف
پک نگهداری             # به‌روزرسانی + ارتقا + پاکسازی در یک دستور
پک راهنما              # راهنمای کامل
```

### محیط فارسی
```bash
پوشه‌ها                 # ls -lah
بساز پروژه‌من          # پوشه بساز و واردش شو
فشرده خروجی *.jpg      # فشرده‌سازی خودکار (zip/tar.gz/...)
بکاپ config.txt        # بکاپ با تاریخ و ساعت
راهنمای_فارسی          # راهنمای کامل فارسی
```

### گیت‌بازکن — انتشار روی گیت‌هاب
```bash
گیت‌بازکن                       # پوشهٔ جاری را منتشر کن
گیت‌بازکن -نام my-repo          # مخزن جدید با نام دلخواه
گیت‌بازکن -خصوصی                # مخزن خصوصی بساز
گیت‌بازکن -پیام "نسخهٔ جدید"    # پیام کامیت دلخواه
```
